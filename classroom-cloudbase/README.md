# 第七讲课堂答题后台

已接通第七讲六道思考题（l07-q1 至 l07-q6）：同一课堂二维码、学生持续登录、每题60秒作答、手动公布匿名分布、按原课件推进解析，以及课后导出全部轮次的具名CSV。题干、参考式和选项从唯一内容源 `quantum-slides/lecture07.qmd` 提取，原有教学内容及答案时机保持不变。

## 当前可用范围

- 正式课件六道思考题均提供页内扫码、倒计时和手动展示分布；需联网连接 CloudBase。离线教学题面、公式、选项和原有答案分步仍可用。
- 本机联调服务复用同一份后端业务逻辑，记录落在被 Git 忽略的 `.local/records.json`；不是云数据库模拟器，也不能证明腾讯云并发性能。
- 学生端和教师端已通过独立浏览器会话联调。云端真实 SDK 身份、数据库事务、权限规则、设备网络和容量必须在环境开通后再验收。
- 不包含真实 AI 调用。统计是确定计数，教师负责判断误区和调整讲授。

## 课堂中的使用流程

1. 直接打开第七讲任一道思考题，二维码、计时与两个按钮位于题面右侧。课前首次输入教师口令连接；同源教师会话继续复用，讲授中无需打开独立教师页。
2. 自动选用当天的“第七讲课堂”，没有时创建；刷新继续使用同一课堂。跨天创建新的课堂，保留往日数据。测试可通过课件查询参数 classroom 指定教师已有课堂；它不授予权限。
3. 学生扫码首次登记姓名、学号，随后保持登录。点击“开始作答”，右侧显示倒计时及已作答总人数，各选项分布保持隐藏。
4. 随时点击“展示回答”可收题并公布统计；时间到后也由教师手动点击。右侧二维码的位置显示A—D人数与比例，原题面仍在。到时不会自动公布，也不提前显示正确答案。
5. 按课件原有下一步揭示答案与理由，再继续讲课。再次答题创建新轮次，已提交答卷继续保存。离开该思考题或隐藏课件时暂停轮询，返回后刷新状态。
6. 各题沿用同一课堂二维码；教师发出下一题后学生自动换题、清空旧选择。返回旧题显示该题自己最近一轮统计；所有轮次仍保留。若上一题未收完，明确发出另一题会关闭上一题的提交，不自动公布其分布。
7. 课后如需具名记录，可进入 classroom/teacher.html 选课堂导出CSV；该管理页不嵌入课堂播放流程。后台保留所有轮次，学生端只看自己的答案与匿名统计。

## 学生“我的答题”与课后开放

学生在课堂作答页点击“我的答题”，使用原有学生会话查看本课堂记录。每题默认显示课堂内最后一轮；该轮未作答独立标记，展开仍可查看此前各轮的选择。作答数和答对数也按每题最后一轮计算，课堂发题序号不表示该题尝试次数。

默认只显示本人选项及“待公布”。课堂“展示回答”不开放答案，也不返回正误字段。教师课后进入 `classroom/teacher.html`，选择对应课堂，点击“开放答案与解析”并确认，才向该课堂学生开放正误、标准答案和简要解析；学生点击“刷新记录”即可读取。其他课堂状态不变。可以收回答案，原有答卷继续保留。

未结束的题目不能开放答案；已开放的课堂若需再发题，先收回答案或新建课堂。学生历史查询按服务端会话的身份和课堂过滤，不接受客户端指定他人身份；未作答不自动判错。历史页面不提供其他学生的记录。

姓名和学号是低门槛课堂身份登记，不证明持有人身份，不适合高风险考试。相同学号必须匹配已有姓名，姓名误填由教师在后台核对修正。此版本没有公开学生名单接口；教师口令独立于学生身份，只有教师会话可开题、看实时人数和导出记录。公开投影不展示姓名、学号。

## 部署步骤

用户只需完成腾讯云注册、实名认证，创建 CloudBase 环境，并告知环境 ID 和地域。后续使用本机 CLI 的浏览器授权，不在聊天中粘贴腾讯云 SecretId / SecretKey。

2026-11-01 实际开通页核对：新环境当前只展示 PostgreSQL；免费体验为6个月、0元，需要从官网显示的公众号领取兑换码。环境名称最长20字符，使用 `qo-classroom`。此前建议的 `quantum-optics-classroom` 超长，不再使用。若创建 PG 环境，先按下述 pgdoc 路线配置并完成云端实测，不能把本地业务测试当作云端通过。

1. 确认该环境已启用**文档型数据库**、云函数和身份认证。此实现使用 CloudBase JavaScript SDK 建立匿名身份，通过 CloudBase HTTP 网关调用事件型云函数，不需要迁移课程网站。
2. 在身份认证中允许匿名连接，创建用于 Web SDK 的 **Publishable Key**。它是可公开的客户端标识，不是腾讯云 SecretKey。匿名身份只用于 SDK 连接；业务端教师/学生的权限另行校验。
3. 安全域名按当前控制台要求添加 `zimin.li`，联调时添加 `localhost` / `127.0.0.1`；不要添加通配来源。仅允许调用 `classroom` 云函数，不开放数据库客户端读写。
4. 创建文档集合 `qo_classroom`，将 `database.rules.json` 设为该集合的安全规则：客户端读写全部拒绝，仅服务器 SDK 访问。没有完成这一项不得用于真实课堂。
5. 根据控制台实际查询提示，为 `{kind,roomCode,_id}` 的导出查询、`{kind,roundId,choice}` 的计数查询建立所需组合索引。核对前端直读/直写数据库确实失败。
6. 运行配置准备脚本，再使用已登录的 CloudBase CLI 部署。秘密文件不进入公开网站。

```sh
node scripts/prepare.cjs --env-id ENV_ID --region ap-shanghai --publishable-key PUBLISHABLE_KEY --gateway-url GATEWAY_URL
tcb login
npm ci --prefix functions/classroom
tcb fn deploy classroom --install-dependency false
```

准备脚本会生成 Git 忽略的 `cloudbaserc.json`，函数环境变量中只放教师口令的 scrypt 哈希；原始教师口令仅保存在权限600的 `.local/teacher-login.json`。已有口令文件会保留。不要启用云函数请求体或响应体全量日志，以免记录学生信息、口令和会话令牌。函数依赖必须以实目录随包上传，避免压缩包将本地链接变成普通文本文件；部署前在本机安装锁定依赖并加载入口检查。生产云函数仅部署 `functions/classroom/`，不部署 `.local/` 或本机开发服务。

HTTP 网关需要启用总开关，为 classroom 配置 `/classroom-api`，并开启该路径身份认证和跨域安全域名校验。当前使用环境默认 API 网关地址，供接口调用；答题页面仍放在课程网站，不通过默认测试域名分发页面。

单函数网关策略见 `function-access.rego`。它只声明 classroom 函数，不允许数据库客户端访问；仍需使用真实入口验证，不能把策略保存当作验证通过。`scripts/cloud-smoke.cjs` 使用两名虚拟学生检查云端完整流程，失败时只报告阶段与错误码，成功报告放在 `.local/cloud-smoke.json`，不保存会话令牌。

7. 部署后验证：SDK 匿名连接、学生身份保持、教师权限拒绝测试、数据库规则拒绝测试、服务端截止、并发提交、重新发题归档、具名CSV。完成云端和浏览器联调后再同步公共配置到课程网站。正式上课前，用至少两部真实手机分别测试微信和系统浏览器，并验证教室网络。未完成的手机或容量检查不能标记通过。

### 当前新建 PG 环境的兼容路线

官方 [pgdoc 插件说明](https://docs.cloudbase.net/database/postgresql/pg-doc) 与 [使用指南](https://docs.cloudbase.net/database/postgresql/pg-doc-usage) 支持使用原文档接口和 Node SDK 事务。PG 环境在 Document 编辑器启用 pgdoc 后，可继续验证现有服务端 repository，无需先重写课堂业务。

- 新建空环境先启用 pgdoc，再建 `qo_classroom`，确认插件的 Enabled 状态。不要在有旧数据的环境中直接开启接管或清空。
- **PG/pgdoc 不支持传统文档安全规则**；上面的 `database.rules.json` 只适用于传统环境。PG 集合应使用基础权限“无权限”，并核对 PostgreSQL 直接访问的 GRANT/RLS 同样不向 anon/authenticated 开放。云函数用管理员服务端身份访问。
- 明确执行匿名客户端直读、直写拒绝测试，以及服务端事务、重复提交和收题竞态测试。插件可用性、实际 SDK 返回格式及免费环境超时/内存配置均以云端验收结果为准。
- CLI 设备登录页面要求先有至少一个环境。环境未创建时显示“暂无可用环境”是开通顺序限制，不应改用长期密钥绕过。

## 数据与权限实现

单集合按 kind 分 room、round、student、session、answer、limit。学生学号只在受保护的数据库及教师导出中出现，学生主键为学号 SHA-256；会话是随机256位令牌，服务端仅存其哈希。学生会话120天、教师会话12小时，退出时服务端撤销会话。前端凭据保存在同源 localStorage，清除浏览器数据后需重新登记。

服务器每次提交都在事务中读取当前轮次和截止时间，然后写入该学生独立答卷，并更新按学生散列分配的16个提交门之一。教师收题会在事务中关闭全部提交门，使并发旧请求产生写入冲突并重试；不依赖数据库把单纯读集合也作为冲突。没有全班争写的单一计数器；教师实时计数使用服务端查询，公布时先完成收题事务，再保存匿名聚合快照。浏览器关闭不影响服务端截止判断。

学生5秒轮询，教师3秒轮询；隐藏页面暂停查询，回到前台刷新。它是近实时显示，不是 WebSocket 毫秒推送。具体上课人数对应的云额度、数据库事务隔离行为及突发并发，待真实环境压测。

## 可选选择原因

每题先独立提交 A–D，之后只返回本人已提交选项对应的原因。`functions/classroom/reasons.json` 是可选原因文案的编辑源，不嵌入课件，也不打包到静态网站。原因单选，可不填；截止或教师展示回答后停止提交。改选会清除旧原因，同选项再次提交则保留。保存原因不改变原答案提交时间，也不增加答题人数。

教师管理页可按当前轮次单独展开原因统计，未填写人数独立列出；投影片的 presenter 不请求也不显示原因。导出含原因编号、原文快照和独立提交时间，学生可在自己的答题记录查看所存原因。原因是学生自述，不能据此断言其真实思维过程；模型分析方式见下文。

## 第七讲手动多轮作答与现场分析（2026-11-02）

课件仅保留“开始回答／再次作答”和“展示结果”。再次作答会结束上一轮并开启新的60秒作答，不公布旧轮统计；教师自行安排讨论时长。展示结果先收题，再按顺序并列展示本题全部轮次。每轮使用自己的实际提交人数作为分母，统一百分比尺度；多于四轮可横向滚动，不限定总轮数。继续翻页或推进原解析时收起结果。

“其他原因”可选填120字以内补充，留空也可保存。主答案与原因分别提交，改选主答案会清除旧原因。学生“我的答题”保留本人的各轮记录；答案解析仍需教师课后统一开放。教师CSV现在有25列，新增“原因补充”，保留题目、选项、正确答案、逐人逐轮对错及原有选择原因。

课件展示柱状图和简短AI小结；详细假设、依据轮次、配对改选、原因覆盖与文字补充仅在课后管理页的“各轮对比与详细AI分析”中显示。人数、百分比、配对变化和覆盖率由程序统计。AI只给核对重点和教学建议，不把投票改变解释为学习效果。送入模型的材料不含姓名、学号或学生主键；文字补充做常见邮箱、长数字和链接遮蔽，预设原因并不是已验证的误概念量表。

模型请求有45秒超时；云函数60秒，前端模型请求65秒。教师认证、每课堂限流、并发单次调用及按题目/各轮数据/模型配置的缓存均在服务端执行。重复展示已有结果不重复请求模型；失败保留图表并提示失败，不伪造小结、不自动转用其他收费模型。

### 模型配置

当前生产配置已切换为自有DeepSeek官方API：`QO_AI_PROVIDER=deepseek`、`QO_AI_MODEL=deepseek-flash`。密钥通过用户授权的本地文件读取，未回显；仅存入云函数环境变量和Git忽略的本机部署配置。原CloudBase托管的`cloudbase / hy3`已完成此前联调，不作为自动备用模型。

用户保留个人版、不升级套餐，现已改用自有API。2026-11-02尝试启用目录中的最新版快照`deepseek-v4.1-flash-1017`时，腾讯接口返回`FailedOperation.PackageUnsupported`，明确要求标准版及以上；未升级套餐。官网标准版标价199元/月，个人版19.9元/月，参见[腾讯云定价](https://buy.cloud.tencent.cn/price/tcb/overview)。目录列出模型不等于当前环境有调用资格。

要直接使用DeepSeek官方API，在`classroom`云函数环境变量中设置：

- `QO_AI_PROVIDER=deepseek`
- `QO_AI_MODEL=deepseek-flash`（可换为账号支持的官方模型名）
- `DEEPSEEK_API_KEY`：用户自己的密钥

官方端点固定为`https://api.deepseek.com/chat/completions`，使用服务端Bearer认证、非流式JSON输出及关闭思考模式以控制课堂等待时间。不通过腾讯的模型调用服务；模型费由DeepSeek账户承担，CloudBase函数/数据库费用仍按套餐计算。参考：[DeepSeek官方API](https://api-docs.deepseek.com/)、[JSON输出](https://api-docs.deepseek.com/guides/json_mode/)。

密钥只能放云函数环境变量或本机忽略文件，不能放`classroom/config.js`、网页、课件、公开仓库或控制台日志。若使用本机忽略的`cloudbaserc.json`维护部署，须同步保存环境变量，避免以后部署覆盖；不要将私有配置提交Git。切换模型会使旧模型缓存失效；不需要改学生页面。

### 课件中的二维码预加载

打开课件即创建六个静态答题框，首个答题框统一连接或选择课堂，其余复用该结果；只有当前题轮询状态，避免各框重复创建课堂。已连接过的同日、同一课堂二维码以PNG缓存，后台确认尚未返回时先显示二维码和禁用的操作区，确认后才启用教师按钮。不同课堂与默认当天课堂分别缓存，避免联调入口串码；跨天缓存不复用。首次使用或新课堂仍需先完成一次连接。

### 安全配置与重复部署

用户可以把密钥放在本地文件中，只提供路径；配置工具读取该文件，不在聊天、命令参数、网页或日志中回显密钥。源文件及私有部署配置权限均设为600。`cloudbaserc.json`和`.local/`不进入Git，密钥不在云函数代码包或静态网站中；运行时仅通过`DEEPSEEK_API_KEY`环境变量读取。原始桌面文件保留，不自动删除。

`prepare.cjs`在同一环境重新准备配置时保留已设置的模型、提供方和API密钥，并收紧私有配置文件权限；切换到不同环境不会自动复制这些密钥，防止意外传到另一环境。模型调用失败不回退至腾讯模型。
